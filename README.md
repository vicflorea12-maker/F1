# F1 Race Radar 🏁

A responsive Formula 1 upcoming-races widget with a live countdown, built with plain HTML, CSS and JavaScript. No frameworks or API keys required.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `f1-race-radar`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. After deployment, open the Pages URL shown there.

## Customise
Edit the `races` array near the bottom of `index.html`. Countdown values update every second in the visitor's browser. The listed dates and race start times are preset for the 2026 season and should be checked against the official calendar for schedule changes.
